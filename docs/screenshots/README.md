# Screenshots

These screenshots show Voite v1.0.0 (build 2282) running on iPhone 16 Pro Max.

## How to Update Screenshots

### On iPhone:
1. Open Voite app (build 2282)
2. Navigate to each screen:
   - **home.png** - Home screen showing daily goal cat and recent recordings
   - **record.png** - Recording screen with red record button
   - **daily-prompt.png** - Daily prompt screen with thought prompts
3. Take screenshots (Volume Up + Side button)
4. AirDrop to Mac
5. Replace files in `docs/screenshots/` folder
6. Keep aspect ratio and resolution (iPhone 16 Pro Max native)

### Recommended Screens to Capture:
- Home screen with some recording progress on the cat
- Recording screen (before starting, showing the big red button)
- Daily prompt screen
- Optional: Library screen, Diary screen, Settings screen

## Image Specs
- Format: PNG
- Source: iPhone 16 Pro Max (1290 x 2796 pixels)
- Orientation: Portrait
- Keep device bezels/chrome for authentic look
